# ImportExportVariables

**ImportExportVariables** is a Figma plugin that simplifies the process of managing variables such as descriptions, strings, and booleans. It enables designers to import and export variables efficiently, saving time and enhancing workflow.

---

## Features

- Export descriptions, strings, and booleans from Figma projects.
- Import variables back into Figma for seamless updates.
- Simple and intuitive interface for managing variables.
- Supports bulk operations to handle large datasets.
